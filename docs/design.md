# D1 «Тяга — помощь и перевозка»: визуальное направление

## Уточнение Codex — 04.11.2026

SVG заменён фотографией реального эвакуатора. Типографика и структура сохранены.
Фото в рамке с подписью маршрута, локальные адаптивные WebP/JPEG, атрибуция и пометка об иллюстративном характере.
Источник/лицензия — docs/assets.md и assets/LICENSE.md. Прежние описания схемы ниже относятся к истории разработки.

Статус: черновик до разрешения реализации. Референсы проверены 04.11.2026.

## Принцип

«Утилитарная ясность»: страница как понятный инструмент, а не «аварийная» декорация.
Светлая композиция, читаемая с телефона на улице при ярком солнце, сильная типографика,
контрастные действия. Никакой имитации аварийной госслужбы: без мигалок, «маячковых» полос,
красно-синих спецэффектов и кричащих анимаций.

## Палитра

- Фон: тёплый почти белый `#F6F5F2`; поверхности-карточки белые `#FFFFFF`.
- Текст/заголовки: чернильно-синий `#12203A`; вторичный текст `#4A5468` (контраст проверяем ≥ 4.5:1).
- Акцент (действия, рамки фокуса): янтарный `#C85103`/`#B34700` на белом фоне — проверяем
  контраст текста на акценте ≥ 4.5:1; как заливка кнопки — тёмно-синяя с белым текстом.
- Разделители/границы: `#D8D5CE`.
- Ошибки/предупреждения: только по сценариям; демо-пометки — серо-янтарная плашка.

## Типографика

- Системный стек, без внешних шрифтов: `-apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`.
- Заголовок H1 мобильного первого экрана: clamp(2rem → 3.5rem), вес 700–750, межстрочный 1.05–1.1.
- Основной текст ≥ 18px на мобиле (не менее 16px), межстрочный 1.5–1.6.
- Числа/шаги процесса — табличные цифры, крупный кегль.

## Мобильный первый экран (направление)

1. Шапка: рабочее обозначение «Тяга» + пометка «демо» (маленькая, не прячем).
2. H1: «Поможем передать диспетчеру маршрут и особенности автомобиля» + 1–2 строки оффера.
3. Одна главная кнопка «Связаться с диспетчером» (полная ширина, ≥ 48px высоты).
4. Строка демо-режима: «Контакты в демо не настроены — откроется памятка с текстом обращения».
5. Оригинальная SVG-схема: легковой автомобиль + эвакуатор, маршрут А→Б (инлайн, ~несколько КБ).
6. Внизу — явные демонстрационные условия: регион, режим работы, «условия демо».

## Поведение

- Анимация только функциональная (фокус, открытие диалога), уважает `prefers-reduced-motion`.
- Диалог памятки — нативный `<dialog>` с фокус-трапом, Esc, возвратом фокуса.
- Без JS: памятка доступна как раскрываемый блок/отдельная секция, контент читается полностью.
- Видимый фокус на всех интерактивных элементах, клавиатурная навигация.

## Материалы

## Итерация 2 (04.11.2026, вечер)

По замечаниям приёмки:

- Шапка собрана в одну строку (1440/1024/768 px): короткие пункты меню, меню скрывается ниже
  1024 px, у бренда прячется подпись ниже 1300 px, кнопка шапки может сжиматься.
- Первый экран компактнее: H1 короче («Перевозка автомобиля эвакуатором»), пояснение — одна
  строка с акцентной левой линией, композиция 0.92/1.08 (текст/схема) от 900 px.
- SVG-схема перерисована: согласованный масштаб техники, ясная геометрия (кабина, платформа,
  задние оси, лебёдка-стяжка, машина на платформе), тени под объектами. Подписи вынесены из SVG
  в HTML-легенду «А — место подачи · Б — место доставки» — они не уменьшаются на мобильном.
- Убраны однообразные белые карточки: «Когда подходит» и «Что сообщить» — списки с линейками
  (2 колонки от 640 px), шаги — плоские колонки с цифрой и верхней линейкой вместо карточек.
  Белые карточки остались только у двух кнопок связи в разделе контакта.
- Фокус: кольцо 3 px; цифры шагов на затемнённом акценте #9A3D00 (контраст с белым 6.9:1).
