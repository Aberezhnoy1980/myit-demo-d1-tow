## Что делаем и что исключаем

Первый срез — базовый одностраничный лендинг без CRM, по структуре задания:

первый экран → когда подходит → что сообщить → условия/ограничения → порядок обращения → FAQ → контакт.

Исключения этого среза (прямо из задания): форма отправки, сервер, карта с внешними запросами,
аналитика, CRM, загрузка файлов. Никакой надписи «заявка отправлена»: без endpoint — только явный
демонстрационный режим.

## Аудитория, оффер, гипотезы

- Аудитория пилота: водитель, которому нужна перевозка автомобиля.
- Отдельные услуги манипулятора/погрузчика не превращаются в три равнозначных оффера.
- Оффер: помочь передать диспетчеру маршрут и особенности автомобиля, чтобы уточнить возможность
  и стоимость перевозки.
- Главное действие на страницу — одно: «Связаться с диспетчером».
- Гипотеза источника перехода: локальная карточка (карты) или рекламная ссылка.
- Регион и режим работы — явно обозначенные демонстрационные условия (город задан условно;
  г. Северск — существующий город, привязки к действующему бизнесу нет).
- Не обещаем: 24/7, прибытие за N минут, фиксированную цену без основания, отзывы, автопарк,
  лицензии, число выполненных выездов.

## Контакты

- Кнопки связи настраиваются в одном конфигурационном файле: реальный телефон, мессенджер,
  подпись получателя. Подстановка случайных действующих номеров, чужих аккаунтов или контактов
  автора объявления запрещена.
- Пока подтверждённых контактов нет: главное действие открывает явно демонстрационную памятку
  «что сообщить диспетчеру» и позволяет скопировать текст обращения. Отсутствие внешних контактов
  объясняется на странице и в README как ограничение локального среза до отдельного подключения.

## Технология

- HTML + CSS + небольшой JavaScript, без обязательного фреймворка и сборщика.
- Содержание (HTML), стили (CSS) и поведение (JS) разделены, без искусственного каркаса.
- Оригинальная простая SVG-схема маршрута/перевозки. Фото — только свои или разрешённые
  (происхождение — в docs/assets.md); чужие машины не выдаются за собственный автопарк.
- Без внешних шрифтов, трекеров и внешних запросов по умолчанию.

## Бюджеты (измерять фактически, не по исходнику)

- CSS + JS суммарно ≤ 60 КБ gzip; собственный JS ≤ 20 КБ gzip.
- Первый экран ≤ 700 КБ переданных ресурсов.
- Метод измерения: gzip реальных файлов (`gzip -c file | wc -c`), состав первого экрана
  фиксируется в docs/acceptance.md.

## Проверки

- Контактные кнопки: configured/unconfigured, корректный URL, текстовый запасной путь при отказе
  копирования в буфер.
- Диалог памятки: открытие/закрытие, Esc, возврат фокуса на кнопку, клавиатурное управление.
- Без JS основное содержание и памятка доступны.
- Длинные подписи, масштаб 200%, липкие элементы не перекрывают контакты.
- Ручной сценарный протокол вместо тестового framework (маленький статический сайт).
- Приёмка по общим условиям: 360/390, 768, 1440 px и промежуточные, WCAG 2.2 AA для
  реализованных сценариев, уменьшенное движение, без горизонтального переполнения, консоль
  браузера, 404 ресурсов, пути под префиксом.
