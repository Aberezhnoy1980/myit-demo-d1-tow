## Задача

Владельцу эвакуатора и спецтехники нужен собственный канал обращений вместо дорогого трафика
с площадки объявлений (источник задачи — объявление Kwork 3228359; с автором мы не работали).
Демо показывает базовый лендинг услуги: как страница приводит водителя к одному действию —
связаться с диспетчером и уточнить перевозку.

## Решение

Одностраничный лендинг «Тяга — помощь и перевозка» (название вымышленное):

- Первый экран называет услугу прямо: «Перевозка автомобиля эвакуатором»; подзаголовок —
  маршрут, состояние машины и согласование условий. Оригинальная SVG-схема с легендой.
- Структура: услуга («когда подходит») → что сообщить → условия → порядок (маршрут и машина →
  уточнение условий → согласование → перевозка) → FAQ → контакт.
- Главное действие — одно. В демо-режиме — «Попробовать обращение»: черновик текста с
  копированием (три ветки: Clipboard API → execCommand → ручная инструкция). При настроенных
  контактах (один файл config.js: empty/phone-only/messenger-only/both, с проверкой формата) —
  «Позвонить/Написать диспетчеру», обе CTA ведут по одному сценарию.
- Постоянный компактный маркер «Самостоятельное демо. Услуга не оказывается»; регион и график
  заданы условно (г. Северск — существующий город, привязки к бизнесу нет). Без выдуманных
  отзывов, цен, автопарка и «24/7».
- Технология: HTML + CSS + небольшой JS без фреймворков и сборщика, без внешних запросов,
  шрифтов и трекеров. 4 файла, ~43 КБ суммарно (12,9 КБ zlib-gzip).
- Светлая утилитарная композиция, системная типографика, видимый фокус, адаптив 360–1440 px,
  reflow-проверка масштаба 200%, режим без JS, диалог с фокус-трапом и без закрытия по backdrop.

## Ограничения

- «Настроен» контакт = техническая настройка ссылки; это не доказательство доставки и не признак
  действующего бизнеса. Внешние контакты не подключены: отправка невозможна, имитации
  «заявка отправлена» нет.
- Форма, сервер, карта, аналитика, CRM, загрузка файлов — не входят в срез.
- Реальный browser-zoom 200% не воспроизводится headless: проверен reflow вдвое меньшего
  вьюпорта (оговорка в acceptance). Safari, Firefox, скринридеры не запускались; WCAG 2.2 AA
  по одному авто-набору не заявляется.

## Как демонстрировать

1. Локально: `cd demo/Landing/d1-tow && python3 -m http.server 8000 --bind 127.0.0.1` →
   http://127.0.0.1:8000 (подробности в README.md).
2. Телефон 390 px: первый экран, «Попробовать обращение», черновик, копирование.
3. Десктоп 1440 px: шапка в одну строку, композиция hero, раздел контактов.
4. Показать состояния конфигурации (вписать телефон/мессенджер в config.js на время показа —
   оба CTA становятся ссылками) и страницу без JavaScript (черновик виден блоком).
5. Честно сказать, чего нет: реальных контактов, доставки, формы, CRM.
